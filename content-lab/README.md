# CeptLens 独立内容实验室 1.0.1

本次修复导入期间预览读取半成品导致的白屏。首次运行和报错处理见 [启动与依赖说明](启动与依赖说明.md)。

从 1.0 升级：先关闭旧实验室终端，备份旧目录的 `content-libraries/`，将新版解压到新目录，再把旧 `content-libraries/` 整个复制进去，运行新版 `start-lab.bat`。不迁移 `node_modules`、`src` 或 `server`。正式平台无须更新。本次没有更改 Node 版本、依赖版本、教学 SDK 或包格式。

这是与正式平台隔离的独立内容实验室，不是正式平台的另一种启动模式。当前已发布在 CeptLens ECS 的 `https://ceptlens.com/lab/`，使用独立 systemd 服务和独立草稿目录；实验室不会连接正式平台数据库，也不会自动发布正式站。

## 启动

Windows：安装 Node.js **22.18.0**，解压到本机独立目录，双击 `start-lab.bat`。保持终端开启，浏览器访问 **http://127.0.0.1:8766/**。

macOS/Linux：在本目录执行 `bash start-lab.sh`。

首次启动会按锁文件安装依赖，需要能访问 npm 软件源或公司的 npm 镜像。无需升级公司已有的 Node 22.18.0。仅支持本机访问；每位协作者启动自己的实验室。

## 线上实验室

线上实验室入口为 **https://ceptlens.com/lab/**，整条路径由 HTTPS 基础认证保护。用户名填写 `developer`，密码填写项目维护者提供的开发者密钥；页面中的导入、校验和导出操作还会再次验证同一密钥。开发者密钥不提交到仓库，也不写入题包。

线上实验室只用于题包设计、预览和审批前测试。当前题目与词条草稿库均为空；原始 34 题保存在仓库的 `content-batches/kv-cache-serving-20260909/`，后续按逐题确认的结果导入。

## 日常工作

1. 在实验室导入一个词条 ZIP（或题目 JSON）；同 ID 更新前会提示确认。没有现成包时下载模板。
2. 修改 `content-libraries/terms/<id>/` 内的教学页面、交互和资源，全部保存后点击“校验与刷新”。内容文件不再逐个热更新，避免读到尚未保存完整的教学包；ZIP 导入成功后当前页面会自动刷新。新增词条应改模板文件夹名、`manifest.id` 和 `view.tsx` 的 `termId`，三者一致，再导入 ZIP。
3. 点击“校验与刷新”，检查显式链接、公式、交互与探索返回路径；查看缺失词条时无需导入整个正式库。
4. 点击“导出当前词条”，下载经过技术校验的运行 ZIP；作者的本地测试文件留在源码目录中。
5. **协作者本人**打开公司正式平台 **http://100.100.40.76:8765/#/developer**，输入管理员提供的内容管理口令并上传 ZIP。无需管理员代收或转交。新增 ID 新增词条，同 ID 更新共享词条。

本实验室没有“自动发布正式站”功能，也不存储正式管理口令。技术校验不等于教学质量审查，提交者仍需检查实际内容。

## 可迁移的数据与源码

- `content-libraries/`：本机草稿库、模板和自动生成的缺失链接索引。更新实验室时单独保留、备份这个目录。
- `src/content-sdk/`、内容页面与样式：与正式站同版本的教学运行组件，不含正式学习业务。
- `server/lab-host.mjs`：本机内容包导入、隔离校验和导出服务，不含账号、考试、批注、助手或正式管理服务。
- `public/docs/LAB_GUIDE.md`：包结构、独立开发、导入和发布指南。

交付包默认是空草稿库，不携带正式题库、词条库、历史审查记录、账号数据或密钥。已有内容需要时从正式站导出单个包，再导入实验室。

旧版 `.modelpath-lab/content-libraries/` 不会自动覆盖或被删除。如需迁移，先备份，再将选中的词条目录压成单词条 ZIP 导入；或在停止新实验室后按 ID 合并到新 `content-libraries/`。不要合并旧 `.modelpath-lab/src/` 或整站源码。

## 开发检查

`npm run check`：内容校验、单元测试、TypeScript 和生产构建。

`npm run test:imports`：在临时副本验证真实导入、同 ID 替换、失败不覆盖、导出和重启保留。不会操作当前草稿或正式网站。

包格式：`schemaVersion: 3.0`、`sdkVersion: 1.x`。依赖与教学 SDK 对齐 CeptLens beta6；与同格式的现有正式站通过 ZIP 交换内容，不通过源码路径互相引用。只在扩展 SDK API 或改变协议时才需要升级工具；日常内容开发不需要更新整站源码。
