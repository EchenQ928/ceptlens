# ModelPath V1.0 beta.2

## 本次修正

- 做题模式按“题目 ID + 学习方式”隔离组件状态。切换题目后，已选选项、答题结果和答案显隐均重新初始化；快速看题模式仍默认显示答案。
- 全站基础字号由 14px 提升至 16px，并同步放大题干、选项、解析、词条正文、筛选表格与操作按钮。
- 词条页删除 aliases 和题目反向索引侧栏，正文区域加宽；右侧改为“题目 → 词条 → 下级词条”的探索路径，可逐级返回。
- 词条章节导航改为页内滚动按钮，避免与 HashRouter 路由冲突。
- 共享词条从 10 个扩展到 26 个；其中 21 个迁移自此前人工审查过的 19 题 Demo 资产，并重新封装为 JSON 内容包和受控 React 可视化。
- 新增 Softmax、过拟合、正则化、Dropout、残差连接、Conv+BN 融合、前向/反向开销、多头注意力、Transformer Block、逐位置 FFN、位置编码、LayerNorm、KV Cache、运行时峰值内存、训练集和验证集等核心页面。

## 验证结果

- 内容校验：37 道 P0 题、26 个共享词条，引用和前置关系完整。
- 单元测试：2 个测试文件、7 个用例全部通过。
- TypeScript 严格构建与 Vite 生产构建通过。
- 浏览器回归：上一题揭示答案并选择选项后进入下一题，答案面板为 0、已标记选项为 0、查看答案按钮保持禁用，直到用户重新选择。
- 浏览器回归：词条路径可形成“第 16 题 → 过拟合 → 训练集”，右侧不再出现 aliases 或题目引用。
