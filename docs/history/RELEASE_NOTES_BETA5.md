# ModelPath V1.0 beta5 · 2026-09-07

## 本次纠正

上一轮已同步新 PC 的功能源码，但正式站仍读取旧的 25 词条库，新设计仅存在于预览目录；页面、包和日志的版本号也未统一。beta5 按用户确认，将新 PC 的最新词条直接用于正式网站。

| 词条 | beta5 正式站 |
| --- | --- |
| 神经网络 | 使用新 PC 重做版：计算函数、传递数值、权重与偏置逐步展开 |
| 全连接层 | 正式新增：连接、权重矩阵、乘法项与输出对应 |
| 多层感知机（MLP） | 正式新增：逐层信号传递和单元计算 |
| 激活函数 | 使用新 PC 重做版：六种函数的图像与数值联动 |
| 损失函数 | 使用新 PC 重做版：回归误差、分类概率、损失与梯度 |
| 反向传播 | 使用新 PC 重做版：前向、反向、参数更新的分步动画 |

正式网站现在为 34 道题、27 个词条，显式待补词条为 72 个。词条正文、示意图、公式、示例和交互实现均以用户传回的 `.modelpath-lab/content-libraries/` 为来源；未重新生成教学内容。独立预览环境仍保留，后续可继续修改。

新 PC 的 5 个预览交互测试文件此前遗漏，本次恢复其中全部 13 个测试，按所属概念拆入 6 个词条包。测试不会进入导出的运行教学包，也不会让删除词条留下站点级失效导入。

## 版本与公司部署

- 包版本、页面徽标和服务日志统一为 beta5，版本源为 `package.json`。
- 公司 Node：22.18.0；无需升级。
- 公司访问地址：**http://100.100.40.76:8765/**。
- `start-lan.bat`、`start-lan.sh`、`npm run host:lan` 均监听 `0.0.0.0:8765`，通过 `--public-host 100.100.40.76` 显示公司访问地址。
- 独立内容预览仍为本机 8766；新版内容现在也能直接在正式站打开。
- `/api/content/status` 返回 `version`、`publicUrl` 和实时内容数量，便于排查是否误开了旧版服务。

## 与 beta1～4 的衔接

对照本地保存的四版交付锁文件，React、Router、Vite、Vitest、TypeScript 等核心版本相同。保留新 PC 新增的代码高亮与发布检查，只将 jsdom 和 Node 类型定义调整为兼容公司 Node 的锁定版本，详见 `NODE22_COMPATIBILITY.md`。

广播监听方式沿用 beta1～4 的 `0.0.0.0:8765`。beta1～2 的 Python 静态服务不提供主机内容发布，因此 beta5 继续使用 beta3～4 的 Node 内容服务和同格式的题目/词条包（3.0，SDK 1.x）。

## 验证记录

验证环境：官方 Node 22.18.0 / npm 10.9.3，macOS ARM64。

- 正式库和预览库分别通过内容校验、18 个测试文件 / 61 项测试、TypeScript 检查及生产构建。
- 逐文件比对确认，正式库全部 27 个词条的运行内容与新 PC 预览库一致，全部 34 道题与新 PC 原题库一致。
- HTTP 实测：发布题目与词条 ZIP、并发写入拒绝、无效内容回滚、构建失败恢复原内容与网站。
- 已模拟公司 Host/Origin 请求，验证不会被同源检查误拒绝；公布地址返回指定公司 IP。
- 已实测删除再导入全连接层，不会被独立测试的固定导入阻塞。
- 浏览器实际查看 beta5 正式神经网络页面，操作计算节点，并沿正文链接进入新版全连接层，保留探索路径。

公司 Windows 的实际网卡、防火墙和入站网络仍需在该主机确认；本机不会冒充拥有公司 IP，也没有修改网卡地址。
