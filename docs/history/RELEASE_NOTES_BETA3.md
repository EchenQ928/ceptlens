# ModelPath V1.0 beta3

## 核心变化

- 把网站、题库、词条库拆成三个可独立升级的模块；内容库不再埋在 `src/`。
- 词条全部改为完整定制教学包：清单、专属 React 教学页面、隔离样式、设计稿、审查报告、资源和测试缺一不可。
- 题目升级到 schema 2.0，并正式预留结构化问答题、分项评分和 LLM 评分指令。
- 删除词库自动命中链接；37 道题和 26 个词条均使用作者显式标注的链接。
- 缺失教学包不再静默失效：页面标注“待补词条”，全库生成 `CONTENT_GAPS.md`。
- 共享词条库统一展示 26 个已完成教学包和 87 个待补词条，支持按状态、ID、来源和原因搜索；待补项不生成空白详情页。
- 修复题库列表等非交互标题泄露 `[[term:...]]` 标记的问题，标题只显示可读标签，题目正文仍保留可点击词条。
- 内容管理改为广播主机持久化。上传包经过口令、解包、全库校验和构建，成功后供所有同事刷新使用。
- 提供单题、题库、单词条包、完整词条库的导入导出，以及跨版本迁移规则。

## 校验结果

- 37 道 P0 题全部通过 schema 与显式链接一致性检查。
- 26 个定制词条教学包结构完整。
- 识别出 87 个后续需补充的教学包 ID，并保留具体依赖来源。
- 29 个测试文件、36 个测试用例通过。
- TypeScript 严格构建与 Vite 生产构建通过。
