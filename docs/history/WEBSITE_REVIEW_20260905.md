> 后续调整：按用户要求，实验室已简化为纯内容预览页。下文编辑器、导入导出、发布 API 的描述是第一轮实现记录，当前不再启用。最新用法见 public/docs/CONTENT_LAB.md。

本次范围是平台功能、内容发布、运行架构、页面交互与独立内容设计环境。没有修改正式题目和词条的教学正文，也没有对全部教学内容进行学术正确性审核。

| 考核页承诺尚不存在的计时、答卷保存和 LLM 评分 | 明确显示筹备状态及待实现功能，不展示无效开考按钮 |
| 内容服务断开仍看似可保存 | 显示连接/发布状态，禁用不可用写操作，定期刷新状态 |

| 完整词条库导出包含源码测试 | 与单词条导出保持一致，排除测试文件 |
| 依赖版本使用 latest，迁移时可能漂移 | 固定为本机已安装版本，更新 lockfile |

## 新增实验室

实验室使用 `.modelpath-lab/` 和 8766 端口。首次复制参考内容，每次启动同步平台源码，后续保留自己的题库和词条。正式端口 8765 的内容、构建和口令不与实验室共享。

编辑器可编辑题目 JSON、词条清单/TSX/CSS/组件文本，接收 JSON/ZIP，调用同一发布流程，使用正式页面 iframe 预览，并导出已验证包。操作方法见 `public/docs/CONTENT_LAB.md`。

## 仍需后续设计的部分

1. **正式考核尚未实现。** 需要身份、抽卷、计时、答卷保存、恢复、计分和复核；补齐主观题不能自动补齐这些能力。
2. **学习记录仍以浏览器本机为单位。** 多设备同步、员工学习统计、管理报表需要独立账户与持久化数据服务。
3. **内容发布仍会重新构建网站。** 对当前内部平台简单可靠；大规模内容、多作者同时编辑时，需要草稿版本、审校状态、变更历史、任务队列等能力。当前并发冲突要求稍后重试。
4. **词条包依赖当前 SDK。** 部分已有交互位于 SDK 的公共教学组件中；跨平台迁移需要兼容 SDK，不是任意网站均可直接运行的独立 ZIP。
5. **隔离实验室不是任意代码沙箱。** React 代码仍需可信内部审查。上线更广泛网络前再设计身份与授权边界。
6. **内容缺口仍为 76 个词条。** 下一阶段按题目真实依赖逐个补齐，并分别检查教学准确性和交互效果。
7. **整库词条 ZIP 目前用于备份。** 网页导入仍以一个教学包为单位，批量词条导入可在实际需要时增加。

## 验证范围

已有与新增单元/交互测试、TypeScript 检查、内容校验及生产构建；实验室 API 的真实发布/失败恢复/并发测试；浏览器页面与交互检查；正式内容及构建的哈希隔离检查。

自动检查不是对所有词条交互的穷举验证，也不代表已完成全部教学内容审核。下一阶段每个包仍应在实验室逐项验证。

本轮验收结果：9 个测试文件、40 项测试全部通过；正式 115 个教学/模板文件哈希无变化。临时验证题目与词条已清理，两个环境当前均为 34 道题、25 个词条、76 个待补词条。浏览器实测通过 JSON 编辑保存、题目到新词条跳转、交互计数及 390px 预览。
