# ModelPath V1.0 beta4

## 内容作者负担

- 题目只维护正文、显式词条链接、分类和排序。
- 词条包只强制最小清单与定制页面；CSS、资源和测试按需添加。
- 删除教学定位、手写依赖、手写目录、设计记录、审查记录、状态和版本等重复字段。

## 灵活性

- 移除 37 道题/P0 数量限制，新增、更新和删除不再受交付快照约束。
- 保留选择题、问答题、前置排序、高级分类和任意定制 React 交互能力。
- 词条删除后自动进入待补目录；真正会破坏学习顺序的前置断链才会阻止题目删除。

## 内容变更

- 按要求删除原题目 1、2、12，题库调整为 34 道 P0 题。
- 删除仅被原题目 12 使用的 `forward-backward-compute-cost` 包，词条库调整为 25 个完成包。
- 显式引用重新审计后，当前自动登记 76 个待补词条。
