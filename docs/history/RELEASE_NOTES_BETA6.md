# ModelPath V1.0 beta6 · 2026-09-07

## 本次功能

- **共享批注与问答**：题目/词条选中文字后右键批注，保留原文，支持回复、修改/撤回自己的内容、标记已解决。其他用户可在同一页查看，5 秒同步。宽屏采用正文旁的讨论面板。
- **学习助手**：常驻浮动入口；选文右键提问或不引用原文直接提问。私人对话与共享讨论分离。暂不接真实 API，明确提示未配置，不生成演示答案。
- **考核开放与重排**：开始界面、30 分钟服务端计时、随机抽卷、自动保存、刷新恢复、交卷、错题与答卷查询。考核期间前后端禁用批注与助手。多选全对才得分。
- **主观题评分接口**：评分要点校验、逐项反馈、失败保留待评分、重试入口。未接 API 不打分；题型缺失或评分未完不发布完整总成绩。

内容库仍为 34 道题、27 个定制词条，保留 beta5 的六个重做词条；没有为了凑试卷新增未经设计的主观题。现有 27 单选、7 多选、0 主观，体验卷实际抽取 5 单选＋5 多选。

## 公司部署

Node 22.18.0 与原锁定依赖保持兼容，公司地址仍是 **http://100.100.40.76:8765/**。新增数据库采用 Node 自带 SQLite，不额外安装数据库服务或原生第三方插件。

首次启动创建 `service-data/modelpath.sqlite`。此目录保存共享讨论、身份、私人助手对话和答卷；升级时停服后整体迁移。Agent 的配置和扩展在 `agent-runtime/`。密钥只存在于主机环境变量，出厂包不含密钥、不含用户数据库。

仍使用浏览器访客身份，未接公司 SSO；它用于当前协作试用，不冒充实名考试账号。真实模型质量、公司 Windows 防火墙、入站连通性没有在本机冒充验证。
