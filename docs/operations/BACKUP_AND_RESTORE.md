# 生产备份与恢复

生产数据位于 `/var/lib/ceptlens`，与代码发布目录分离。备份必须写入服务器之外的受控存储，不能放入 iCloud 同步目录或 Git 仓库。

## 最低要求

- 每日备份 SQLite 数据库及其 `-wal`、`-shm` 文件（服务短暂停止或使用 SQLite 在线备份工具，保证一致性）。
- 备份文件加密传输、限制访问，并保留至少 7 个日备份和 4 个周备份。
- 每次部署前确认最近一次备份成功。
- 每月至少做一次恢复演练，并记录恢复时间、数据完整性和改进项。

## 恢复步骤

1. 停止 `ceptlens` 服务，保留当前数据库目录副本用于取证。
2. 将选定备份恢复到临时目录，校验文件权限和 SQLite 完整性。
3. 用临时数据目录启动服务，检查 `/api/content/status`、登录/学习数据和最近答卷。
4. 确认数据完整后替换 `/var/lib/ceptlens` 中的数据库文件，设置所有者为 `ceptlens`。
5. 启动服务并检查 `systemctl is-active ceptlens`、首页、内容状态和关键 API。
6. 记录恢复点、缺失数据、耗时和后续修复事项。

恢复演练不得使用真实用户数据对外提供服务；优先使用隔离的临时主机或本地副本。
