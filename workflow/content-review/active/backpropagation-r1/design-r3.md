# 反向传播 r3：完整函数 → 参数偏导 → 计算复用 → 更新

用户明确读者已经掌握偏导。上一版把偏导概念拆成反复增减 0.01，知识起点过低、文本多且效率低。本轮取消微小量试改、六步导航与逐项揭示。

直接给出同一两层网络的完整预测函数和标量损失函数，明确 x/y 固定、四个权重偏置为自变量。训练需要损失对参数的偏导，预测对参数的偏导只属于中间链路。

可视化改为参数选择器：选择 w1/b1/w2/b2，同时高亮计算图中的依赖路径，显示完整链式法则（偏导乘积 → 运算表达式 → 数值代入）。默认展示 w1 的最长链路，四个梯度默认都可见，不要求连续点击才能拼出概念。

随后用紧凑公共项演算解释反向传播的算法特点：从损失得到 g=∂L/∂ŷ，复用 g 算第二层参数及 δ=∂L/∂z，再用 δ 算第一层参数。求导目标与反向算法的关系要明确；不能将所有求偏导的方法都叫反向传播。

统一更新仍保留可验证的按钮，但从求导交互中独立出来，显示同一梯度对应的四参数更新与新预测/损失。公式即主讲解，不再用大段文字翻译普通代数。分支、ReLU 不可导点和 batch 规则折叠为补充说明。PyTorch 代码与这组数学对象一一对应。
