# 反向传播 r5：固定计算图上的两轮训练

读者知道偏导。目标不是重新解释导数，而是让读者跟踪：同一次前向产生哪些值 → 链式法则怎样复用这些值和中间偏导 → 四个参数如何根据本轮梯度更新 → 下一轮重新计算。

## 页面

1. 完整预测函数，用嵌套 underbrace 就地标出 z、h；平方损失紧随其后。简短说明输入、目标和四个可学习参数。
2. 一个完整动画，默认停在初始化。固定学习率 0.025，固定可复算的初始参数，不加学习率对比。播放／暂停、上一步／下一步、重播、进度拖动。
3. 默认收起 PyTorch 两轮代码及边界细节；一句总结。

## 动画的视觉语法

- 五个固定位置依次是 x、z、h、ŷ、L。节点写运算和结果，前向箭头随当前运算流动。
- 对应位置保留 ∂L/∂ŷ、∂L/∂h、∂L/∂z，反向流动显示路径。不用 g、δ 引入记忆负担。
- 四个参数卡片固定在图下：原值、已求梯度、新值。当前参数卡与当前公式同时突出。
- 底部仅显示当前这一步的符号公式、数字代入、一句操作说明。每次只揭示一个新结果，已知结果保持稳定。
- 所有动画帧由时间线索引确定，允许暂停、倒退、定位，不通过连锁 state 更新制造不一致。

## 两轮的边界

每轮先完成前向，再按预测偏导、w₂、b₂、h、z、w₁、b₁的顺序求导。显示四项更新时使用同一份旧参数和梯度，逐项展示新值，全部准备好后统一进入下一轮。第二轮结束再做一次前向验证，不执行第三次更新。
