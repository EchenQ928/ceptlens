# 损失函数 r2：读图顺序与调整方向

本轮保留四段结构、数值曲线与分类曲线，修复用户指出的信息层级及推理断层。

1. 入口明确并列的两类任务，突出“数值预测 / 类别预测”和各自计分对象。
2. 数值段先解释一批样本各有预测与目标，再用本例初始 A/B/C 的偏差说明不能直接平均有符号偏差来衡量整体误差大小。
3. 图前明确横纵轴含义，图内轴标题加粗；图例直接突出“绝对误差 / 平方误差”及对应运算、线型，不突出空泛口号。保留曲线、控件及批次表的联动。
4. 批次表后解释同一个正损失不包含方向，但训练保留整个计算关系并求梯度。以目标 3、预测 1 和 5 为静态对照：单样本平方损失均为 4，对预测的梯度分别为 −4、+4。用明确的文字和相向箭头指出预测应增大/减小。
5. 区分“对预测的梯度”与最终参数梯度；批次取平均后每项贡献乘 1/3，实际共享参数的方向由整批样本经反向传播共同决定。最小必要解释留在本页，完整过程链接反向传播。

视觉使用现有中性灰、深色加粗和品牌红；不增加装饰图标、复杂控件或手机端工作。

验证：数值和分类原有交互回归；方向示例独立有限差分与 PyTorch 对照；桌面浏览器检查轴标签、规则识别、排版与公式；真实导入器校验最终包。Skill 本轮无修改，应用已有信息层级、对象对应和由浅入深规范。
