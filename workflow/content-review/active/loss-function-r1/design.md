# 损失函数：实现前设计

读者知道模型会做预测，但不要求知道梯度、概率对数或训练 API。页面独立成立。用户本轮授权损失函数与反向传播两项，分别交付。

学习顺序：预测与目标共同进入计分规则 → 数值任务怎样计分 → 类别任务怎样计分 → 公式、框架调用与训练位置。

核心认识：损失是按任务定义的计分规则，不是某一个特定公式。相同预测偏差可以采用不同惩罚方式；训练最小化所选择的损失。

1. 首屏画预测、目标双输入汇入损失函数，输出一个损失值。先定义对象，不从梯度或指标边界开场。
2. 数值预测：目标为 3，初始预测为 1。只改变预测，比较绝对误差和平方误差的曲线、算式。图中明确这是单个样本；三个样本的表格再展示怎样平均得到 MAE/MSE。样本 A 随控件变化，B=3、C=5 固定，目标均为 3。默认 MAE=4/3，MSE=8/3。恢复与对称偏差必须同步。
3. 类别预测：目标类别为猫，默认概率 [0.6,0.24,0.16]。只改正确类别概率；其余概率调整以维持总和 1。概率条、负对数曲线和损失同步。默认损失 -ln(0.6)。不用类别是否猜中取代连续计分。
4. 公式在机制之后；代码对应固定初值。CrossEntropyLoss 传原始分数，本例通过概率取对数构造可复现的演示分数，并说明真实模型的接口。

交互问题：同样偏差按不同规则受到什么惩罚？正确类别得到不同概率时损失怎样变化？各控件只改一个量。

验证：边界、命中目标、对称误差、恢复、平均值、概率和、81 点数值核对；真实 PyTorch 跑页面代码；桌面视觉、链接及最终 ZIP 真实导入规则。
