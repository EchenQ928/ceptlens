# 视觉系统说明

这是一套受华为公开数字页面启发、但属于 ModelPath 自己的内部产品设计系统，不复制华为商标或把产品冒充为华为官方站点。

## 公开参考形成的方向

- 华为官网与企业业务页普遍采用清晰的大栅格、黑白主体和少量红色强调；红色承担入口、当前状态与关键数据，不铺满页面。
- 华为 H Design 的公开介绍强调把设计语言、规范、模式和组件沉淀为统一系统，因此本项目把色彩、字号、间距、边框和布局全部收敛到设计 token。
- 华为开发者公开规范给出 Huawei red `#CE0E2D` 用于品牌登录按钮；本产品不是华为品牌资产，使用独立的 `#C7000B` 作为相近但自有的强调色，并明确不使用华为 Logo。
- 题库页参考 CodeFun 的高密度列表逻辑：筛选、搜索、状态、标签和题目在一个工作区中连续呈现；本产品进一步保留固定前置顺序与工程链路。

## ModelPath token

- 强调红：`#C7000B`
- 主文字：`#111214`
- 反色面：`#17181B`
- 页面底色：`#F4F5F6`
- 分隔线：`#D9DCE1`
- 内容最大宽度：`1560px`
- 桌面布局：224px 侧栏 + 弹性主内容；学习页为题目索引 / 正文 / 上下文三栏

## 排版规则

- 题库采用行式列表，避免每题一个大卡片。
- 红色只标识当前项、关键入口、词条链接和错误状态。
- 元数据使用 10–12px，题目正文保持 13–15px，学习页题干 24px。
- 词条正文的可读宽度约 760px；左右空间用于目录和上下文，不把正文无限拉宽。
