# Visual System

The visual system preserves the original CeptLens product design: a dense operational workspace, a restrained black-and-white base, and a small red accent used for navigation state, key entry points, content links, and errors.

## Tokens

- Accent red: `#C7000B`
- Primary text: `#111214`
- Inverted surface: `#17181B`
- Page background: `#F4F5F6`
- Divider: `#D9DCE1`
- Maximum content width: `1560px`
- Desktop shell: `224px` navigation plus flexible content
- Learning layout: question index, main content, and context columns

## Layout rules

- Keep the question catalog as a dense list for scanning and comparison.
- Use red for state and action meaning, not as a full-page background.
- Keep metadata at 10 to 12px, question body text at 13 to 15px, and learning-page stems near 24px.
- Keep term reading width near 760px; use the surrounding space for the table of contents and context.
- Preserve existing class names and interaction states when translating content.

This document describes the current UI contract. It is not a request to redesign the product.
