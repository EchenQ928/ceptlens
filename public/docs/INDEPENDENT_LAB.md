# 独立实验室与内容协作

正式站与实验室现在是两个独立项目、两个交付包：

- 正式站负责学习、考核、共享讨论和内容发布，沿用公司地址 http://100.100.40.76:8765/。
- 独立实验室负责本机教学包导入／替换、源码修改预览、技术校验、导出，不包含正式平台的账号、考试、批注、助手服务或数据库。

把独立实验室 ZIP 发给协作者即可，不需要发送正式站源码。协作者本机使用 Node 22.18.0，运行实验室包的 `start-lab.bat`，在 http://127.0.0.1:8766/ 设计。每个人的草稿库独立。

完成后，**协作者本人**导出教学 ZIP，访问公司正式站“内容管理”，输入管理员向他提供的内容管理口令并上传。同 ID 更新共享词条，新 ID 新增；发布通过后其他访问者刷新即可看到。

没有新增审批、代收、转交环节。实验室不存正式口令，也不自动连接正式站；发布权由正式站现有管理口令控制。内容管理口令允许增删改共享内容，应只交给可信内容开发同事。教学包包含执行源码，技术校验不是恶意代码沙箱。

两站维持 3.0 内容包格式和 1.x 教学 SDK。日常题目或词条开发不需要修改整站源码；只有平台功能、SDK 或协议变化才升级程序。现有公司 beta6 不需要先升级就能接收该实验室导出的包；本次正式包仅清除旧的混合实验室入口与同步代码。

旧 `.modelpath-lab/content-libraries/` 草稿未删除。先备份，再按需导入单个词条包或停止实验室后按 ID 合并到新实验室的 `content-libraries/`；不要迁移旧实验室内复制的整站 `src/`。
