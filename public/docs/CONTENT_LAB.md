# 内容预览

打开 http://127.0.0.1:8766/，顶部选择“词条”或“题目”，再选择要看的内容。下方直接展示页面。

这里只保留内容本身的排版、公式和教学交互；题目可展开参考答案查看效果。没有源码编辑器、管理菜单、考试、收藏、进度、导入导出或发布流程。

启动方式仍是 `npm run lab` 或 Windows 双击 `start-lab.bat`。

后续由开发工具直接修改 `.modelpath-lab/content-libraries/` 中的题目或词条源码，预览会自动更新。第一次启动复制正式内容作为参考，以后保留独立内容副本。正式平台的 `content-libraries/` 不受影响。

此页复用正式的题目组件和词条正文，只省去网站外围功能。预览服务仅监听本机 8766 端口，不启动内容发布服务。旧版实验室的编辑、保存、导出说明与 API 验证脚本已不再适用。
